# FullStackOpen

A collection of exercises (work in progress) from the university-accredited course (modern web development), curated by The University of Helsinki

## List of Topics Learned, by Part (updated as progressed)

### Part 1: React
- React Basics
- JavaScript
- State

### Part 2: Communication With the Server
- Rendering collections and modules
- Forms, POST/GET/PUT methods
- Basic Styling using modular vanilla CSS

### Part 3: Programming a server w/ Node.js & Express
- Node.js/Express
- Deploying to Render
- MongoDB
- Form Validation using Schemas & ESLint

### Part 4: Testing Express servers, user administration 
- Testing backend using node:test and supertest
- Token authentication using JSON Web Tokens
- Hashing passwords using bcrypt

### Part 5: Testing React Apps 
- props.children
- Testing React Apps: Unit & Integration tests using React-Testing-Library and Vitest
- E2E testing using Playwright

### Part 6: Adv. State Management (Curr)
- Redux
- Reducers, useReducer
